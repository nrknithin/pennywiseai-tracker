# Provenance

FinTrack is a private fork of **PennyWise AI** (`sarim2000/pennywiseai-tracker`),
taken at commit `c512c7c`, and is licensed under the GNU Affero General Public
License v3.0 — see [`LICENSE`](LICENSE).

The application has been renamed throughout: package `com.nrknithin.fintrack`,
application name "FinTrack". No upstream name, logo or banner artwork is used,
which is what the upstream trademark policy asks of a fork.

**This file is the one deliberate exception to "no upstream references".** It is
attribution, not branding. The AGPL attaches obligations when software is
*conveyed* (distributed) or offered over a network; a fork kept private on one
machine triggers none of them. But if this repository ever leaves that machine —
shared, published, or handed to anyone — the licence and this notice are what
make that lawful, and removing them would not.

`docs/FORK-CHANGES.md` records every upstream file this fork modifies and why.
